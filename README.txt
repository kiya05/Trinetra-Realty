TRINETRA REALTY WEBSITE REDESIGN
================================

Files:
- index.html       Home
- about.html       About
- properties.html  Property listings/filter
- blog.html        Blog/insights
- contact.html     Contact/enquiry
- styles.css       Responsive design + minimal animations
- script.js        Mobile menu, cursor effect, reveal animations, filters
- assets/trinetra-logo.png  Provided Trinetra logo

Design:
- Minimal black/white/cream palette with restrained gold accents
- Responsive for desktop, tablet and mobile
- Sticky responsive navbar
- Subtle cursor ring animation on desktop
- Subtle scroll-reveal animation
- SEO title/description/canonical tags on each page
- Semantic headings and image alt text
- No heavy animation libraries

Important:
- The contact form is a front-end demo. Connect it to WordPress, Formspree, your CRM,
  email service, or a custom backend before production.
- Replace representative image URLs with your own optimized property images for production.
- The existing site contains placeholder/theme text such as "Luxus Real Estate"; this redesign
  removes that branding and uses Trinetra Realty consistently.
- Current contact information and broad market positioning were based on the public website.
