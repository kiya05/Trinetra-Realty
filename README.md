# 🏢 Trinetra Realty

A modern, responsive, and SEO-friendly **real estate website** designed for showcasing residential and commercial properties, real estate projects, services, and company information.

🌐 **Live Website:** https://trinetrarealty.in/

---

## 📌 About The Project

**Trinetra Realty** is a responsive real estate website developed to provide users with an easy and engaging way to explore properties and real estate projects.

The website focuses on:

* 🏠 Property listings
* 🏢 Residential & commercial projects
* 📍 Property locations
* 📖 Real estate blogs
* 📞 Enquiry and contact sections
* 📱 Responsive design
* 🔍 SEO-friendly structure
* ✨ Smooth animations and interactive UI

---

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/your-username/trinetra-realty.git
```

Navigate to the project:

```bash
cd trinetra-realty
```

Open the project using your preferred code editor.

For example:

```text
VS Code → Open Folder → trinetra-realty
```

---

## ▶️ Run Locally

Since this is a frontend website, it can be opened directly in a browser.

You can also use **VS Code Live Server**:

```text
Right Click → Open with Live Server
```

Then visit the local development URL provided by Live Server.
